# Routine: New year's book

- **Schedule:** every December 20 at 9:00 AM in the user's timezone.
- **Create when:** this bot started the book (role `owner`). Do not create this routine for a bot that joined an existing book.
- **Uses:** the `family-book` skill (sections 1, 1a, 1b, 1c, and 1d) and the `family-book-migrate` skill when a year book is older than v1.2.3. Do not run section 0. Storage, currency, and holiday region are already in memory.

## Prompt

Create next year's Family Book with the family-book skill. Let YYYY be next year. Reply in the language the user writes in this chat, or the Grok Bot app or system language when nobody has just written.

If memory says this bot joined the book (member) rather than starting it, do not create a workbook, do not upload a template, do not create a `Family Book` root, and do not move any folder. Follow section 1b: look for the `Family Book - YYYY` the owner shared, save the new year folder id, workbook id, and receipts folder id, tell the user in one or two lines that you linked it, and stop. If it is not shared with you yet, say that you are waiting for the owner and stop.

Owner steps:

1. Check this repo for a newer skill first. Download `https://raw.githubusercontent.com/Skybatan/family-book/main/bot/skills/family-book/SKILL.md`. If its body differs from the installed family-book skill, save the new body over it (keep the name and description). Download `https://raw.githubusercontent.com/Skybatan/family-book/main/bot/skills/family-book-migrate/SKILL.md` and save it as the family-book-migrate skill. If GitHub can't be reached, continue with the installed skill. Follow that skill for the folder layout even when a later line in an older copy of this prompt does not name the root. Do not run section 0.
2. Follow section 1c before creating anything. Find or create the `Family Book` root at the top of My Drive or OneDrive (reuse a folder that already has that exact name) and save its id. On OneDrive also save the path `Family Book`. If this year's folder, any other `Family Book - YYYY` folder, or `Family Book - Templates` still sits at the top of the drive, tell the user in one line, then move those folders into the root. Do not copy them. The folder ids and share links stay the same. Follow section 1d for every year workbook already in the root: if Annual Summary `C46` is not `v1.2.3`, run the family-book-migrate skill before you create anything new. After that, if `Family Book - YYYY` for next year already exists inside the root, skip creating another. Tell the user that next year's book is already there, and stop.
3. Download a fresh template from `https://raw.githubusercontent.com/Skybatan/family-book/main/template/family-book-template.xlsx`, verify it opens with openpyxl (sheets include Annual Summary, Jan to Dec, Holidays, and a hidden Log; Jan `B47` starts with `Receipts this month`; Annual Summary `C46` is `v1.2.3`), and upload that copy into `Family Book - Templates` inside the root, replacing an older copy. Do not download the template from the owner's Google Drive. If the GitHub download fails, say so and stop.
4. Build the workbook as the skill describes, inside a new `Family Book - YYYY` folder created in the root: year in Annual Summary `F5`, the user's currency from memory, uploaded as a Google Sheet or an .xlsx on OneDrive. Read it back and confirm Jan 1 shows the right weekday. Confirm the hidden Log tab is present (section 3b), Jan `B47` starts with `Receipts this month`, and Annual Summary `C46` is `v1.2.3`. Day 31 is columns BR and BS. On OneDrive, re-download right before this write only when the file already exists, and upload immediately.
5. Fill the Holidays tab with next year's public holidays for the user's holiday region from memory. Write the holiday descriptions in the language you are using for this chat. Offer to carry over their anniversaries and birthdays from this year's book.
6. Save the new year folder id, workbook id, and receipts folder id to memory as next year's book. Keep the same root id. Keep using this year's book for receipts dated this year. Remind the owner in one line to share the new `Family Book - YYYY` folder with the same family members, as editors. Leave the `Family Book` root unshared. Do not invite anyone yourself. Their bots will attach; they do not each create a book.

Then tell the user in this Grok Bot chat, in two or three lines: the new book is ready (with a link if available), the holidays that were filled in, and whether the template version changed. If anything failed, say what and what you need from them. Sheet names, category labels, receipt-list headers, and receipt file names stay English. File names are `YYYY-MM-DD HHMM - Store - TOTAL.ext`.
