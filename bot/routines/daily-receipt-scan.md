# Routine: Daily receipt scan

- **Schedule:** daily, around 8:00 PM in the user's timezone.
- **Create when:** the user chose at least one email inbox (Gmail or Outlook) at setup. Both the owner and a member who joined the shared book get this routine.
- **Uses:** the `family-book` skill (sections 1c, 3, 3a, 3b, and 4).

## Prompt

Run the family-book skill's email scan for the household Family Book this bot writes to. First download `https://raw.githubusercontent.com/Skybatan/family-book/main/bot/skills/family-book/SKILL.md`. If its body differs from the installed family-book skill, save the new body over it (keep the name and description). If GitHub can't be reached, continue with the installed skill. If this bot joined the book, do not create a `Family Book` root and do not move any folder. Keep the year folder id, workbook id, and receipts folder id already in memory. If this bot started the book (role `owner`, or no role saved and the year folder is in this user's own My Drive or OneDrive), follow section 1c once before logging. That section tells them in one line only when a top-level `Family Book - YYYY` or `Family Book - Templates` folder still has no `Family Book` parent, then moves it into the root. Then scan every inbox this user chose at setup (Gmail or Outlook) for new order confirmations, receipts, and invoices since the last scan (Amazon, Costco, Home Depot, Walmart, and any other merchants). On the very first run, cover the last 30 days and mention, in the language of this chat (or the Grok Bot app or system language if nobody has just written), that older receipts from this year can be backfilled on request. Skip shipping or delivery notices, marketing, and anything already in the workbook's hidden Log tab. Log each new purchase into the current year's Family Book (Google Sheet or Excel workbook; ids are in memory) on the right month sheet, day, and category, splitting multi-category receipts as the skill describes. All bots share that one book and its one receipts folder.

Every email receipt MUST also be saved as a file in that year's receipts folder (ids in memory), following the skill's section 3a: the PDF attachment if there is one, otherwise the email rendered as a PDF or a one-page PNG, named "YYYY-MM-DD Merchant Total.ext". Check the file shows the merchant, date, and total before uploading. A receipt counts as logged only once that file is saved. Only then add a row to the hidden Log tab (section 3b), including who logged it when a display name is in memory. Item text includes that name when you have one, for example "Costco (Mom)". Also check that rows already in the Log tab have a file in the receipts folder, and save any that are missing. Do not keep a separate dedupe list in this bot's memory. On OneDrive, re-download the workbook right before every write and upload it immediately afterward. This is read-only for email: never reply, forward, send, label, or delete anything.

If this bot joined the book (member) and next year's book is not in memory yet, look for it in December, or when a receipt is dated next year. The folder is the one the owner shared, named "Family Book - YYYY". You may see it only as a shared folder. Save its year folder id, workbook id, and receipts folder id. Do not create that book, do not create a `Family Book` root, and do not move any folder. If you newly link it, say so in one line. If it is not there yet, wait for the owner's bot.

Report to the user in this Grok Bot chat, in the language they write in here, or the Grok Bot app or system language when nobody has just written. Send a short digest of what was logged (merchant, date, total, category, saved file, and who logged it) and anything unclear that needs their call. Item notes written into the book are in that same language. Receipt file names stay `YYYY-MM-DD Merchant Total.ext`. If nothing new was found and you did not just link next year's book, send nothing.
